# WhatsApp AI Sales Bot

ИИ-бот продажник для WhatsApp на базе Green API, с архитектурой,
позволяющей позже перейти на официальный Meta Cloud API без переписывания кода.

## 1. Получите ключ Gemini (бесплатно)

1. Зайдите на https://aistudio.google.com/apikey
2. Войдите через Google-аккаунт, нажмите "Create API key"
3. Скопируйте ключ — это будет `GEMINI_API_KEY`

Бесплатный лимит: до 15 запросов в минуту и 1500 запросов в день для
gemini-2.0-flash (актуальные цифры уточняйте в консоли Google AI Studio,
Google периодически их меняет). Для старта этого более чем достаточно.

## 2. Подключите Green API

1. Зарегистрируйтесь на https://green-api.com
2. В личном кабинете нажмите "Создать инстанс", выберите тариф "Разработчик" (бесплатно)
3. Откройте инстанс → отсканируйте QR-код телефоном с установленным WhatsApp
   (Настройки → Связанные устройства → Привязать устройство) — так же, как
   привязываете WhatsApp Web
4. Скопируйте со страницы инстанса `idInstance` и `apiTokenInstance`
5. В том же личном кабинете найдите раздел "Настройки" инстанса → включите
   `incomingWebhook` и впишите Webhook URL (получите его на шаге 4 ниже,
   вида `https://ваш-сервер.onrender.com/webhook`)

Важно: на бесплатном тарифе "Разработчик" бот будет работать только с 3 чатами.
Для реальной работы с клиентами понадобится тариф "Бизнес" (~690 руб/мес,
безлимитные сообщения).

## 3. Разверните код

```
npm install
```

Заполните `.env` (скопируйте `.env.example` и впишите значения) или,
если деплоите на Render/Railway — впишите те же переменные в разделе
Environment Variables панели хостинга.

Локальный запуск:
```
npm start
```

## 4. Деплой на Render (бесплатно)

1. Залейте эту папку в репозиторий на GitHub
2. На render.com: New → Web Service → выберите репозиторий
3. Build Command: `npm install`, Start Command: `npm start`
4. В Environment Variables добавьте все переменные из `.env.example`
5. После деплоя скопируйте адрес вида `https://ваш-проект.onrender.com`
6. Впишите `https://ваш-проект.onrender.com/webhook` как Webhook URL в
   настройках инстанса Green API (шаг 2.5 выше)

## 5. Настройте CRM — таблицу клиентов в Google Sheets (бесплатно)

1. Создайте новую таблицу на https://sheets.google.com
2. Переименуйте нижнюю вкладку листа в `Клиенты` (важно, именно так, с большой буквы)
3. В строку 1 впишите заголовки (для удобства просмотра, бот их не трогает):
   `chatId | Имя | Статус | Последнее сообщение | Первое обращение | Обновлено`
4. Скопируйте ID таблицы из адресной строки браузера:
   `docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_КУСОК/edit` → это `GOOGLE_SHEET_ID`
5. Зайдите на https://console.cloud.google.com → создайте новый проект (или используйте существующий)
6. В меню слева: APIs & Services → Library → найдите "Google Sheets API" → Enable
7. APIs & Services → Credentials → Create Credentials → Service Account
   Дайте любое имя, роль можно не назначать, нажмите Done
8. Откройте созданный сервисный аккаунт → вкладка Keys → Add Key → Create new key → JSON
   Скачается файл — внутри есть поля `client_email` и `private_key`
9. `client_email` → это `GOOGLE_SERVICE_ACCOUNT_EMAIL`
   `private_key` → это `GOOGLE_PRIVATE_KEY` (вставьте как есть, вместе с `-----BEGIN PRIVATE KEY-----`)
10. Вернитесь в таблицу Google Sheets → нажмите "Настройки доступа" (Share) →
    добавьте туда `client_email` из шага 9 с правами "Редактор"
    (без этого шага бот не сможет писать в таблицу — сервисный аккаунт не имеет
    доступа к вашим личным файлам по умолчанию)

## 6. Настройте Telegram-бота для уведомлений и отчётов

1. В Telegram найдите **@BotFather** → отправьте `/newbot` → следуйте инструкциям
   → получите токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   → это `TELEGRAM_BOT_TOKEN`
2. Напишите вашему новому боту любое сообщение (например "привет"), чтобы открыть с ним чат
3. Узнайте свой `chat_id`: найдите в Telegram бота **@userinfobot**, напишите ему
   `/start` — он пришлёт ваш числовой ID → это `TELEGRAM_ADMIN_CHAT_ID`
4. После того как заполните обе переменные в Render и передеплоите сервис,
   подключите вебхук Telegram — откройте в браузере (замените значения на свои):
   ```
   https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://ваш-проект.onrender.com/telegram-webhook
   ```
   В ответ должно прийти `{"ok":true,"result":true,...}`
5. Теперь напишите вашему боту в Telegram `/report` — должен прийти отчёт
   по клиентам из таблицы (или "Клиентов пока нет." если таблица ещё пустая)

С этого момента при каждом новом клиенте в WhatsApp вы будете получать
уведомление в Telegram, а по команде `/report` — сводку по всем клиентам
и их статусам (новый / в диалоге / заинтересован / отказался / готов к менеджеру).

## 7. Переход на официальный Meta Cloud API в будущем

Когда будете готовы перейти на официальный API:

1. Пройдите настройку в Meta for Developers (Phone Number ID, постоянный токен)
2. В переменных окружения смените `WHATSAPP_PROVIDER=green` на `WHATSAPP_PROVIDER=cloud`
3. Заполните `WHATSAPP_TOKEN`, `PHONE_NUMBER_ID`, `VERIFY_TOKEN`
4. В настройках вебхука Meta укажите тот же URL `https://ваш-проект.onrender.com/webhook`

Логика ИИ и промпт (`ai.js`, `prompt.js`) трогать не нужно — они не зависят
от провайдера.

## Структура проекта

```
server.js              — точка входа, выбор провайдера, приём вебхуков (WhatsApp и Telegram)
ai.js                   — вызов Gemini, хранение истории диалога, оценка статуса клиента
prompt.js               — системный промпт (5 этапов продаж, языки, тематика, критерии статуса)
crm.js                  — сохранение и чтение клиентов из Google Sheets, формирование отчёта
telegram.js             — отправка уведомлений и отчётов в Telegram
providers/greenApi.js   — отправка/приём сообщений через Green API
providers/cloudApi.js   — отправка/приём сообщений через официальный Cloud API
```

## Что можно донастроить

- **Текст промпта** — редактируйте `prompt.js`, менять код нигде больше не нужно
- **Долговременная память по клиентам** (сейчас история хранится в памяти сервера
  и сбрасывается при перезапуске) — при росте проекта стоит подключить простую
  базу (например, SQLite или Redis), чтобы не терять контекст диалога
- **Передача менеджеру** — сейчас бот просто пишет, что передаст менеджеру;
  для реальной передачи стоит добавить уведомление вам в Telegram/почту при
  достижении 5 этапа
